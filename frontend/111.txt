我在进行一个黑客松项目，要写一个总结对比不同AI Agent思考过程，并可视化思考路径的项目，项目整体思路如下：

1. **初始界面**  
    用户进入网页时，页面底部只显示一个类似命令行的输入栏，用于输入并提交 Prompt。

2. **多 Agent 处理与评分**  
    提交后，输入栏会向上延长，显示出一个benchmark，展示各个 Agent 的运行状态和评分。
    所有候选回答生成后，系统自动选出评分最高的回答。

3. **展示最终结果**  
    模型在思考时，网页中出现一个可拖动、平移的大画布（Canvas），并在画布中创建一个处于加载状态的节点（Block）。
    同时评分最高的回答会从后端交给另一个本地 AI 模型进行总结。
    整个流程完成后，画布中央的节点结束加载，展示总结后的内容。

4. **查看原始数据**  
    每个原始节点的上方都有一个淡出的节点，用于展示原始json文件
    原始节点上方提供一个可点击的展开箭头，展开后淡出的节点会下移，展示 Prompt，以及完整的原始 JSON 返回数据。
    每个json节点下方中也应该有一个可点击的展开箭头，点击箭头可以返回显示原始节点的状态。

5. **Skills 导出设定**  
    同时每个节点需要有一个打勾框，在通过打勾选择了一些节点之后，屏幕右上会出现一个按钮叫“Export Skills”。
    用户可以使用打勾框来选中自己需要的节点。
    按下“Export Skills"按钮之后可以导出一个markdown格式文件，里面是内容可以作为下一次传输给所有 Agent 的 Skills 的一部分。

6. **连续提问与思维导图**  
    用户可以继续在底部输入问题。每次追问都会在当前节点右侧生成一个新节点，并通过箭头连接，逐步形成类似思维导图的结构。

我负责前端设计和开发，技术栈统一使用 **Vite、React、Tailwind CSS 和 TypeScript**。

本阶段优先完成前端界面和交互，后端只需要提供简单的模拟接口，不接入真实模型。
Agent 处理、评分、选优和总结过程都用模拟数据与延迟演示，同时提供模拟的模型返回内容和 JSON 示例。

整体色调使用深色模式，背景可以使用黑色中混合一点点蓝色，节点的思维导图的色调使用蓝色和白色，所有圆角统一设置成一个数值
